# 🦀 FranzBCContainerHelper 

I do not like the BC Container Helper from Microsoft which is why I decided to make my own. It is not that the BC Container Helper wouldn't do it's job. In my opinion it is way to bloated for my daily use cases. But this project is mainly to practice Rust which is why it won't start off using all of the best practices and is avoiding additional crates. Later I might add a MCP server so your AI agents can utilize the tools this BC Container Helper will provide. Do not take this project to seriously jet, who knows where this will go. Probably nowhere.
