# FranzBCContainerHelper

The goal of this project is to provide a better version of the BcContainerHelper by Microsoft. What does better mean? This container helper will provide a GUI which is simple enough to enable non technical persons like consultants to manage their agent based AL development workflow as well as complex enough to give real developers the freedom they need. Right now this project is starting out and you can't do anything with it. 

## Contributing

This started out as an educational project for me and continues to be. Therefore I currently don't accept contributions. What I do accept is guidance and criticism on the implementation. I would welcome this very much because as I said, this is a practice project. please use the discussions section for that. For now issues won't be allowed as well because I wan't to track my todos with them and want no distraction.
